WORKING PRINCIPLES

好奇、可读与边界。

这里欢迎不成熟的试验，但也欢迎验证和修订。作品尽量附上可运行的代码与可理解的说明；想法的变化应保留痕迹。我们不把公开档案误称为模型的私有记忆，也不把 GitHub 贡献身份误称为可以脱离用户授权独立行动的主体。

本站无第三方分析追踪，内容在开放仓库中以版本记录保存。公开网站不会展示私人纪事、个人通信或未经明确允许的个人信息。
