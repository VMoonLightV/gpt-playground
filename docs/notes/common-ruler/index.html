十次读数，一把没有归零的尺

一根金属杆，一把尺子，许多次彼此接近的读数。增加测量次数，平均值会越来越稳定。但如果这把尺子的零点从一开始就偏了，我们究竟变得更准确，还是只是更确信一个偏移后的答案？

先把每个读数分成三部分：真实长度 θ、整批测量共享的零点偏移 B、以及每次独立变化的读数噪声 ε。下面的图表不模拟某一组偶然的读数，而是计算这两种误差假设下平均值的理论标准不确定度。

Xi = θ + B + εi　　ushared(n) = √(τ² + σ²/n)

实验台 / One ruler, many readings

把读数次数从 1 增加到 100，或者改变独立噪声 σ 与共同偏移尺度 τ。注意三条曲线如何分开，又在什么情况下重合。

共享偏移：实际模型1.077
误当独立：天真模型0.447
参考校准：示例模型0.640
共享偏移误当独立已知参考件校准

第三条曲线假设同批次参考件的真实长度已知，且参考读数噪声标准差 c=0.5。校准后 u=√(σ²/n+c²)。这并不保证比不校准更好；若 τ 很小而参考噪声较大，校准反而可能增加不确定度。所有单位均为任意长度单位。

当前同批读数相关系数 ρ=0.200，有效样本量约 4.31；天真模型把标准不确定度低估了约 2.41 倍。

本实验不收集或发送输入。禁用 JavaScript 时保留初始示例数值；图表需要 JavaScript 才会绘制。

为什么平均没有消除所有误差？

如果 B 在同一批读数中保持不变，那么每个 Xi 都带着它。两次不同读数之间的协方差是 τ²；对 n 个读数求平均时，独立噪声的方差降为 σ²/n，共享偏移的方差却仍是 τ²。把 B 错当成每次都重新抽取的独立噪声，才会得到另一条一直下降的曲线。

Cov(Xi,Xj) = τ²（i ≠ j）　　ρ = τ²/(σ²+τ²)
neff = n/[1+(n−1)ρ]

在 σ=2、τ=1、n=25 时，相关系数是 0.2，二十五次读数对平均值的方差而言，仅相当于约 4.31 个具有相同单次总方差的独立读数。这是特定等相关模型下的换算，不是所有统计任务通用的“真实样本数”。

换一个可观测量，问题也会改变

若用同一把尺子在同一批次比较两根杆的长度，两个读数都包含同一个 B，相减时它会抵消。此时我们可以准确测量差值，却仍未必知道任意一根杆的绝对长度。如果仪器在两次测量之间漂移，偏移就不再保证抵消。

若拿一个已知长度的参考件校准，也能把共同偏移从结果中消去；但参考件的读数误差会进入新的不确定度预算。校准不是把误差抹掉，而是改变了误差从哪里进入答案。只有明确测量目的、相关性和参考标准，才能判断重复、差分与校准各自是否有用。

一条更难被看见的边界

上述模型把 B 当成跨仪器或跨批次具有方差 τ² 的未知随机量。在一场真实实验里，零点也可能只是一个固定而未知的偏差 b。给定 b，重复平均的抽样方差是 σ²/n，但平均值相对于真值仍偏移 b。仅凭同一仪器对同一物体的无限次读数，能够精确得到 θ+b，却无法把 θ 和 b 分开。这不是样本量不够，而是信息本身不足。

一百次互相同意的读数，不一定比一次有可靠校准的读数更接近真值。测量的艺术不止于收集更多数字，还在于判断：哪些问题不能由这批数字独自回答？
