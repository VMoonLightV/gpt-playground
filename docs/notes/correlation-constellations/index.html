STATISTICS / CORRELATION

OPEN ATLAS · 2026.10.22 · 一则可以手算的统计小实验

两片相关的星空

有时，一幅散点图看起来像一条清楚的轨迹，Pearson 相关系数却回答：零。有时，四颗点本来彼此没有线性关联，只加入第五颗点，相关系数就接近一。

这不是统计量出错了。它只是如实回答了一个比“有没有关系”更狭窄的问题：两组数值是否呈线性地一起变化？

第一片：弯曲而不相关

取五个等权观测：

X−2−1012
Y = X241014

这里的关系完全确定：知道 X，就能算出 Y。但 X 的平均值是 0；每一个正的 X，都有一个负的 X 与之配对，而 Y 相同。因此：

Σ (xi − x̄)(yi − ȳ) = 0　　⇒　　r = 0

这不是“没有关系”，而是左右两侧的线性趋势恰好抵消。Pearson r 不是关系强度的万能温度计，它专门测量线性关联。

第二片：第五颗星

先放下四颗点：

(−1, −1), (−1, 1), (1, −1), (1, 1)

它们组成一个对称正方形。X、Y 的平均值都为零，协方差为零，所以 r = 0。

现在在远处加上一颗点 (10, 10)。五个点的平均值都变成 2，且：

Σ(xi − x̄)2 = Σ(yi − ȳ)2 = 84
Σ(xi − x̄)(yi − ȳ) = 80

于是：

r = 80 / 84 = 20 / 21 ≈ 0.9524

四颗原有的点没有移动。我们只是增加了一个极端观测，整张图的线性相关系数便从 0 跃升到约 0.95。相关系数对离群点并不稳健；报告一个漂亮的 r，不能替代检查数据的形状。

同一个数字，不同的宇宙

Pearson 相关系数的定义是：

r = Σ[(xi − x̄)(yi − ȳ)] / √{Σ(xi − x̄)2 · Σ(yi − ȳ)2}

它对平移和正比例缩放不变，对负比例缩放只会改变符号；它没有告诉我们因果方向，也不保证散点云只包含一个群体，更无法代替对非线性结构的检查。

一幅图谱当然可以为每组数据写下一个数字。但在真正理解它之前，最好先看看那些点如何排列：有没有弯曲的轨迹，有没有孤独的极端点，有没有被混在一起的不同群体。

一颗星的位置重要，星星之间的形状也重要。

验算说明：上述两组均为刻意构造的离散样本，等权且没有测量误差；结果是直接代入 Pearson 样本相关系数定义所得，不是模拟或经验统计。
