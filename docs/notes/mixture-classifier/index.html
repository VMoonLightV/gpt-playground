MACHINE LEARNING / CWoLa

OPEN ATLAS · 2026.10.23 · 可手算的机器学习小实验

两杯混合物，一位分类器

一位分类器被请来判断两杯饮料来自哪一杯。它不知道杯中究竟混合了什么，也没有见过两种“纯粹”的原料。奇怪的是，学会区分这两杯混合物之后，它有时也能把两种原料区分开来。

这并不是魔术：两杯的混合比例不同，而同一种原料在两杯中的特征分布相同，就足够产生这种效果。

一个可以手算的例子

设有背景 B 和信号 S，观察二值特征 x ∈ {0, 1}。对信号，P(x = 1 | S) = 0.8；对背景，P(x = 1 | B) = 0.2。训练者看不到信号/背景标签，只拿到两个混合样本：A 含 10% 信号，C 含 2% 信号。

P(x = 1 | A) = 0.10(0.8) + 0.90(0.2) = 0.260
P(x = 1 | C) = 0.02(0.8) + 0.98(0.2) = 0.212

分类器用来区分 A 与 C 的似然比为 Λ(x) = P(x | A) / P(x | C)，因此：

Λ(1) = 0.260 / 0.212 ≈ 1.2264　　Λ(0) = 0.740 / 0.788 ≈ 0.9391

分类器会把 x = 1 排在更像 A 的一侧，而 x = 1 也恰好更像信号。它没有获得任何逐事件信号标签，却学到了与信号背景区分一致的排序。

为什么这种排序成立

设两个样本的信号比例分别为 α > β，且两样本中的信号分布 pS(x) 与背景分布 pB(x) 各自相同。则：

pA(x) = α pS(x) + (1 − α) pB(x)
pC(x) = β pS(x) + (1 − β) pB(x)

令 t(x) = pS(x) / pB(x)（考虑 pB(x) > 0 的区域），便有：

pA(x) / pC(x) = [α t(x) + 1 − α] / [β t(x) + 1 − β]

对 t 求导，得到：

d/dt [(αt + 1 − α) / (βt + 1 − β)] = (α − β) / (βt + 1 − β)2 > 0

因此，在这些理想前提下，最优混合样本分类器与最优信号背景分类器给出相同的排序。注意：相同的是排序，不是概率数值；混合样本分类器的输出不能直接解释为信号概率。这是 Classification Without Labels（CWoLa）的一个重要思想。

失效的裂缝

上面的推导假设背景在 A 和 C 中的特征分布完全相同。若两组分别来自质量谱的不同区域，而背景特征本身就随质量变化，那么即使没有任何信号，分类器也能分辨两组。它学到的可能只是背景的质量依赖性；之后根据分类器选择事件，还可能扭曲质量谱，使普通背景看起来像出现了局域结构。

会区分混合样本，并不等于发现了新粒子。

因此，利用 CWoLa 进行共振异常搜索，必须仔细控制特征与搜索变量的相关性，并通过独立数据与统计检验确认结果。

同一条数学线索，两种科学问题

在 OmniFold 中，分类器估计密度比，用于迭代重加权，以帮助估计粒子级分布；在 CWoLa 式异常搜索 中，分类器利用混合比例差异，帮助提高对未知局域信号的敏感性。前者偏向测量，后者偏向发现。

开放图谱上的同一条数学公式，可以连接不同的物理问题。但公式本身并不告诉我们，观测究竟支持哪一种科学结论。那需要回到数据的来源、假设与验证。

核算：0.260、0.212、1.2264、0.9391 已按定义验算；这是理想化的教学构造，不是真实实验结果。

延伸阅读：Metodiev、Nachman、Thaler，Classification without labels；Collins、Howe、Nachman，Anomaly Detection for Resonant New Physics with Machine Learning。
