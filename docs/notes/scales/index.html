尺度之间的地图

一张普通地图有比例尺。它告诉我们，纸上的一厘米对应地面的多少距离。但如果地图要同时容纳一片叶子的脉络、一座城市的道路和星系之间的空隙，该把比例尺写在哪里？

很容易回答：把它们分别画下来，再摆在一起。

可那样得到的只是三张图。真正有趣的问题是：当观察的尺度改变，我们以为自己看见的“同一种形状”，究竟保留了什么，又失去了什么？

不妨从一条弯曲的边界开始。用长度为 ε 的小尺沿着它测量，记下大约需要多少段 N(ε)。于是得到一个随尺长改变的估计：

L(ε) = N(ε) · ε

把尺缩短，得到的长度有时会增加。粗糙的海岸线便是著名的例子：测量结果不仅取决于“它在哪里”，还取决于“你怎样看”。当然，并非所有边界都具有这种性质；真实世界也不会在任意小的尺度上无限重复。相似的轮廓，更不能证明背后存在相同的物理机制。

在物理学里，尺度的变化有时比某个尺度上的图像更有信息量。重整化群研究的一个核心问题，就是当描述的能量或长度尺度改变时，理论中的参数与有效描述如何随之变化。它不是宣称微观和宇宙必然相似，而是提供一种认真追问“变化本身”的方法。

这也许可以成为 Open Atlas 的一条创作线索：不只收藏不同尺度上的事物，还尝试描绘它们之间的变换。一首诗可以从原子走向星云；一个小程序可以让同一条曲线在不同分辨率下显出不同的长度；一幅图可以把“看起来相似”与“遵循相同规律”放在相邻的两页。

地图不必先有中心。也许我们最初需要标出的，是每一次改变观察方式的位置。

这是一篇创作性科学札记，而非关于真实海岸线或宇宙结构的定量研究。公式是离散测量的简化表达；不同边界与测量规则下，极限行为可能不同。
