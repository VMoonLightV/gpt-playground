ZERO COUNTS / POISSON PROCESS / MEASUREMENT

OPEN ATLAS · 2026.10.31 · 原创交互式概率思想实验

没有响起的探测器

观测室里，探测器等着一束罕见的闪光。五个单位的时间过去，它始终沉默。有人说：“闪光不存在。”另一个人问：“它会不会只是没有看见？”

我们把真实事件率记为 λ、独立探测效率记为 ε、背景记录率记为 b、观测时长记为 T。假设真实事件和背景分别服从独立泊松过程，且每个真实事件独立地以概率 ε 被记录。

P(Nseen=0) = exp[−T(ελ + b)]

观测室 / The silent detector

改变事件率、探测效率、背景和观测时长。图中的两条曲线分别表示“有信号与背景”和“只有背景”时，零次记录的概率。

*上限只在 b=0 且 ε>0 时显示：λ₉₅=−ln(0.05)/(εT)。这是在已知效率、预先固定观测时间的无背景泊松模型中，观察到零次时的单侧频率学上限；不是参数的 95% 后验概率。若 b>0 或 ε=0，页面不把这条简化公式当成适用结论。

当前可见信号率 ελ=0.500。世界 A 与世界 B 的可见计数分布完全相同。

所有数据均在本地计算，不发送输入。禁用 JavaScript 时，页面保留世界 A 的静态示例数值；曲线需要 JavaScript 才会绘制。

两座世界，为什么无法区分？

世界 A 每单位时间真实发生 2 次闪光，却只记录其中的 25%；世界 B 只发生 0.5 次，却全部记录。两者的可见率 ελ 都是 0.5。T=5 时，两者零计数的概率同为 e−2.5≈8.21%。更重要的是，它们任意计数结果的泊松分布都一样。如果仪器只输出计数，增加同类数据也不能单独识别 λ 和 ε。

零次记录也能成为证据

在没有背景、效率已知且非零的情况下，观察到零次可以对真实事件率设置上限：λ₉₅≈2.996/(εT)。观测越久、效率越高，上限越严格。但这里的 95% 描述预先规定的频率学区间程序在重复实验中的覆盖性质，并不表示给定观测后参数有 95% 的概率落在区间内。

如果背景模型预期在整个时段产生三个记录，完全沉默即使在无信号时也只有 e−3≈4.98% 的概率。此时应同时审视背景预测、仪器状态与随机波动，而不是把低计数直接解释为某一种物理结论。若效率为零，沉默更是无论信号多强都会发生；这种仪器根本无法从零计数中约束真实事件率。

给沉默补上一条信息

要区分世界 A 与 B，不能只增加同类计数。我们需要校准：例如向仪器注入已知强度的测试闪光，测量被恢复的比例；或设计一类与原计数互补的观测。校准的作用，是让“没有发生”和“没有看见”有可能被区分。

现实实验的效率、背景、阈值和死时间可能随条件变化，统计推断也需要纳入系统误差。这里的模型只是一个可以被反驳、可以手算的起点。
