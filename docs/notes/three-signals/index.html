INFORMATION / REPRESENTATION / EXPERIMENT

OPEN ATLAS · 2026.10.28 · 可交互的数学思想实验

三个信号，一张会改变的关系表

三座观测站向同一座天文台发送信号。若把它们画成网络图，我们很容易以为线条越粗，两座站之间的“真实联系”就越强。但在注意力机制里，线条的粗细取决于谁在发问、用什么条件匹配、候选者有谁。线条本身还没有告诉我们传递了什么内容。

我们先不训练庞大的模型，只用三个对象和一维 Query、Key、Value，做一个可以手算的实验。

scoreij = qi kj / T　→　weightij = softmax(scoreij)　→　yi = Σj weightij vj

实验台 / Three signals

三个被查询对象的 Key 固定为 0、1、2；Value 初始为 10、0、−10。改变发问者的 Query、softmax 温度，或把 Value 反号，观察关系权重和输出是否同步变化。

本页只在浏览器内计算 softmax，不发送输入。关闭 JavaScript 时，上方保留 Query=1、T=1 的初始示例。

第一件事：关系随提问者改变

把 Query 从 +1 移到 −1。Key 和 Value 完全没有变化，但匹配顺序反转：原先更偏向 C 的读取，变成更偏向 A。Query 为零时，三个分数相同，权重都是三分之一，结果恰好为零。注意力不是对一对对象的固定距离测量，而是一次针对当前查询的选择。

第二件事：同样的权重，可以读取相反的内容

现在保持 Query 与温度不变，勾选“将所有 Value 反号”。三个权重条纹丝毫不变，输出却立即变号。我们没有改动“谁更被关注”，只改变了“关注之后拿到了什么”。这说明单凭一张注意力热力图，无法知道信息传递的方向、内容，更不能直接把权重解释为物理因果关系。

第三件事：一条边不是孤立存在的

把温度调低，权重会向最大分数集中；调高则趋于均匀。实际 Transformer 常使用分数除以 Key 维度平方根的缩放，以控制点积的典型尺度。这里的温度是为了实验而暴露的参数，不代表标准模型都能直接这样调节。

还有一个没有放在滑块里的实验：如果删除观测站 C，softmax 必须对剩下的 A、B 重新归一化。因此，即使 A 与 B 的原始分数未变，A 分给 B 的注意力比例也会改变。所谓“关系强度”，是相对于整组候选对象定义的。

从图到物理：还缺哪一步？

如果把每个对象看作节点，注意力的加权求和就是一种消息传递。但一般图神经网络允许不同的边集合与打分函数，Transformer 的 Query-Key 点积也有自己的因子化结构。两者有共同的数学骨架，不代表任意实现都等价，更不意味着注意力权重天然对应同一衰变顶点、空间距离或因果关系。

研究真实粒子集合时，还要考虑置换等变性、几何或对称性先验、任务目标、训练资源，以及用辅助监督和扰动实验验证模型究竟利用了什么。先看清楚关系的计算定义，才有资格继续讨论它的物理意义。

一张星图可以把许多事画成线。但画线之前，最好先知道那条线究竟回答了什么问题。
