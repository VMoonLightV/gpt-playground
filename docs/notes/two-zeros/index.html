QUANTUM PHYSICS / SYMMETRY

OPEN ATLAS · 2026.10.25 · 双态思想实验

两种零，一次跃迁

一个零写在对易子里，另一个零写在矩阵元里。它们看起来都在说“不可以”，但回答的并不是同一个问题。

第一个零问：在系统自己的演化中，什么量能够保持确定？第二个零问：给系统施加某一种扰动时，哪两个状态能被它连接？

把它们混在一起，就容易把“好量子数”和“选择定则”误认为同一件事。我们用一枚只有两个量子态的假想小星体，看看两个零怎样各自工作。

第一个零：哈密顿量与可观测量对易

设系统的哈密顿量为：

H₀ = (Δ / 2) σz，　Q = σz，　Δ > 0

这里的 σx、σy、σz 是 Pauli 矩阵。H₀ 的两个能量本征态是 |+z⟩ 与 |−z⟩，能量分别为 +Δ/2 和 −Δ/2；它们同时也是 Q 的本征态，本征值分别为 +1 和 −1。

[H₀, Q] = 0

只由 H₀ 控制的时间演化不会把一个确定的 Q 本征值变成不确定的叠加。Q 在这套动力学中是守恒量，q = ±1 可以作为标记定态的好量子数。注意，这还没有说外界能否激发一次跃迁。

第二个零：要看究竟用什么算符敲门

现在给系统施加弱的含时驱动 V(t) = g(t) A。一阶跃迁振幅包含：

𝒜i→f(1) ∝ ⟨f|A|i⟩ ∫dt g(t) exp[i(Ef − Ei)t/ℏ]

先选择 A = σz。两个不同能量态之间有：

⟨+z|σz|−z⟩ = 0

这个驱动在一阶微扰下不能使两态互相跃迁；事实上在这个简单模型里，整个含时哈密顿量始终在 σz 基底中对角，因此它在任何阶都不会混合这两个态。

但如果保持 H₀ 完全不变，只把驱动换成 A = σx，便有：

⟨+z|σx|−z⟩ = 1

现在跃迁不再因矩阵元为零而被禁止。它仍不保证一定发生：驱动的频谱、持续时间与能量差也会决定跃迁概率。

选择定则不是能级表自己写出的判决，而是初末态与相互作用算符共同决定的约束。

当第一种零消失，第二种零也可能改变

再改变系统本身：

H = (Δ / 2) σz + ε σx
[H, Q] = −2i ε σy

只要 ε ≠ 0，原来的 q = ±1 就不再是完整哈密顿量的好量子数。新能量本征态是旧基底的混合，能级间隔为：

Ω = √(Δ² + 4ε²)

有趣的是：仍用原先不能引起跃迁的 A = σz 来驱动，现在它在新能量本征态 |E+⟩、|E−⟩ 之间的矩阵元却满足：

|⟨E+|σz|E−⟩| = 2|ε| / √(Δ² + 4ε²)

例如，取 Δ = 2、ε = 0.75（同一能量单位），新能级间隔是 2.5，矩阵元绝对值为 0.6。原来那个零消失了。

这里不是“同一个选择定则无缘无故失效”，而是完整哈密顿量改变了本征态；计算矩阵元所使用的初末态也随之改变。

两个零之外

真实原子的电偶极选择定则涉及角动量、宇称和跃迁算符的张量性质，比这个双态模型丰富得多。这里的 σz 和 σx 是刻意选择的教学算符，不能直接当成真实原子的电偶极算符。

要问某个量子数是否仍然“好”，先看它对应的算符是否与完整哈密顿量对易。要问某次跃迁是否被禁止，再看给定相互作用算符在实际初末态之间的矩阵元；若不为零，还要检查驱动的能量和时间结构。

星图上的两条线都可以标成“不可通行”，但一条是道路本身不存在，另一条是你手里的钥匙打不开那扇门。

校核：理想双能级模型；√[2² + 4(0.75)²] = 2.5，2(0.75)/2.5 = 0.6。不包含真实原子的谱线强度、寿命或完整选择定则。
