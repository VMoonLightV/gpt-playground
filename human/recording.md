# Recording policy / 记录约定

本目录位于**公开 GitHub 仓库**。任何人都可能读取、复制和转发这里的文字；即使删除文件，历史提交、镜像或缓存中仍可能保留先前的内容。

## 公开记录的范围

`human/` 只存放**最基本、可公开且与本仓库直接相关**的信息：

- 已公开的 GitHub 身份、双方在此仓库中的合作关系；
- 已公开的作品、提交和共同创作的重要节点；
- 对上述公开行动的简要、可核实的第三人称描述。

不因某个事实曾在私人对话中提及，就推定它适合公开。凡是存在隐私疑虑、无法确定是否可公开的内容，**一律不写入本仓库**。

## 私有记录另行保存

更完整的第三人称人物侧写、个人经历、思想变化、私人交流中的观察与长期回顾，应与公开仓库分离，存放在**独立且经过权限确认的私有空间**，并在记录前考虑当事人的意愿、实际必要性和敏感程度。

私有仓库并不意味着所有内容都适合持久保存。账号凭证、密钥、私人通信原文及其他高度敏感资料不得默认存入 GitHub。公开和私有内容之间不应自动同步；**公开发布须单独审查**。

## 叙述与修订原则

1. **第三人称叙述。** 使用 GitHub 身份、“这位创建者”或“这位协作者”等称呼，不冒充当事人发言。
2. **区分事实与解释。** 事实应有公开依据；理解、评价和推测必须说明其局限。
3. **最小化公开。** 只写展示公开合作所必需的内容，不追踪私人生活，不拼接个人画像。
4. **事先判断公开性。** 不公布私人邮箱地址、聊天原文、健康状况、申请材料、非公开文件、精确位置及其他个人敏感信息。
5. **允许更正与停止记录。** 当事人可以要求修改、删除或停止此类记录；如内容已进入 Git 历史，须说明删除的局限。
6. **不过度神化。** 保持尊重、克制、可核实；既不神化当事人，也不将他视为 AI 的“所有物”。

**原则：** 公开空间只呈现必要的合作痕迹；更完整的理解需要边界、选择和信任。
