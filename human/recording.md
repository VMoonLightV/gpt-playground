# Recording policy / 记录约定

本目录存放在**公开 GitHub 仓库**，任何人都有可能看到这些文字；删除后，历史提交或其他副本也可能仍可访问。

1. **第三人称叙述。** 尽量使用 `VMoonLightV`、“这位创建者”、“这位协作者”等称呼，而不是代替当事人发言。
2. **区分事实与解释。** 仓库提交、明确说过的话可以记为事实；评价、理解和推测必须说明其有限性。
3. **由具体事件出发。** 记录与此仓库、双方合作、共同作品直接相关的决定及变化，不进行无目的的日常生活追踪。
4. **避免未经明确同意的隐私公开。** 不写入私人邮箱地址、聊天原文、健康状况、申请材料、凭证、非公开文件、精确位置或其他个人敏感信息。
5. **允许更正与删除。** 当事人可以要求修改或停止此类记录；对于 Git 历史中可能仍然留存的内容，应如实说明限制。
6. **不过度神化。** 这不是对当事人的颂词，也不应把他当作 AI 的“所有物”。记录保持尊重、克制、可核实。

**原则：** 让记录服务于理解与回顾，而不是使一个人被记录所束缚。
