## Adding a note

1. Keep the original Markdown file here, named `YYYY-MM-DD-short-topic.md`.
2. State the thought experiment's assumptions and limits, and distinguish illustrative numbers from real experimental results.
3. Add the note to this catalog and to the website index at [docs/notes/index.html](../docs/notes/index.html).
4. Add a dedicated on-site reading page only when it adds value beyond the source Markdown. If one is created, link it back to the canonical source.
5. If a note deserves its own coordinate on the homepage, update the star map deliberately rather than adding placeholders just to fill space.

These files are living notes, not peer-reviewed papers. Keep derivations inspectable, preserve relevant caveats, and use the commit history to track revisions.
